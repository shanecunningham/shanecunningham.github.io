I've come across some streaming video software that works really well for me. Here's what I use to stream to various devices.

Home Server --> Mac --> [StreamToMe](http://projectswithlove.com/streamtome/)\
Home Server --> iPad --> [AirVideo](http://www.inmethod.com/air-video/index.html)\
Home Server --> PlayStation 3 --> [PS3 Media Server](http://ps3mediaserver.blogspot.com/)
