# cunninghamshane.com

Source for my personal blog, built with [Hugo](https://gohugo.io/) and a small custom theme (`themes/mono-pop`), deployed to GitHub Pages from `main`.

```sh
hugo server -D        # local preview at http://localhost:1313/
hugo new content posts/my-post.md
```

Posts live in `content/posts/`. Older posts (2010 to 2018) are marked `archived: true` and kept as they were written. See `CLAUDE.md` for conventions.
